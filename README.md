# Spordivaim veebileht

Selle lehe kood on lihtsates HTML-failides — igaüks saab neid GitHubi veebiliideses otse muuta, ilma programmideta.

## Failid
- `index.html` — avaleht
- `tunniplaan.html` — nädala tunniplaan
- `kalender.html` — treenerite kalender (Google Calendar embed)
- `aastaplaan.html` — õppeaasta treeningplaan
- `styles.css` — kogu lehe kujundus (üldjuhul pole vaja muuta)
- `assets/logo.png` — klubi logo

## Kuidas midagi muuta
1. Mine GitHubis oma repositooriumisse.
2. Ava fail, mida soovid muuta (nt `tunniplaan.html`).
3. Vajuta pliiatsi-ikooni ("Edit this file").
4. Muuda ainult teksti — mitte nurksulgudes olevaid `<...>` märgendeid.
5. Kerige alla ja vajuta "Commit changes" (roheline nupp).
6. Umbes minuti pärast on muudatus veebilehel näha.

## Kuidas lehte avalikuks teha (GitHub Pages)
1. Repositooriumis mine "Settings" → "Pages".
2. "Branch" alt vali `main` ja kaust `/ (root)`.
3. Vajuta "Save".
4. Mõne minuti pärast on leht saadaval aadressil, mis on kirjas Pages lehe ülaosas (nt `https://spordivaim.github.io`).

## Kalendri seadistamine
Vaata täpseid samme lehelt `kalender.html` (jaotis "Kuidas kalendrit seadistada").
